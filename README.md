# GTI V2

## Overview

GTI V2 (Generation Trading Intelligence Version 2) is a professional Python-based ICT / Smart Money Concepts trading engine.

The project is being developed using an Architecture-First methodology where every implementation is governed by approved specifications, frozen architecture, and sprint-based development.

## Development Methodology

Every implementation follows this workflow:

1. Requirement Lock
2. Architecture Review
3. Implementation
4. Code Review
5. GitHub Commit
6. Sprint Closure
7. Blueprint Update

No code is written before architectural approval.
